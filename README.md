# [대학원 프로젝트] AI-Hub 국내 여행로그 데이터(동부권) 연구

AI-Hub의 **'국내 여행로그 데이터(동부권, 2023)' (데이터셋 번호: 71778)**를 기반으로 한 대학원 연구 프로젝트 작업 공간입니다.

---

## 1. 디렉토리 구조 및 운영 원칙

```
D:\paper\b\
├── temp\                   # [필수] 작업 중 발생하는 모든 임시/캐시/추출 파일 저장소
├── data\
│   ├── raw\                # AI-Hub 원천 다운로드 파일 (CSV, JSON, JPG)
│   ├── processed\          # 정제, 결측치 보정, 피처 엔지니어링 완료 데이터
│   └── samples\            # 고속 파이프라인 검증 및 단위 테스트용 샘플 데이터
├── docs\                   # 프로젝트 제안서, 첨부 지침 파일, 연구 방법론 문서
├── notebooks\              # EDA, 분포 시각화 및 실험 노트북
├── src\
│   ├── config.py           # 경로 설정 (D:\paper\b, temp 등) 및 메타데이터 정의
│   ├── data\               # 데이터 로더, 전처리, 지리정보 변환
│   ├── models\             # 추천 및 예측 모델 아키텍처
│   └── utils\              # 평가지표(Recall, NDCG), 하버사인 연산 등
├── tests\                  # 단위 테스트 및 환경 검증 스크립트
├── .gitignore              # temp 폴더 및 대용량 데이터 git 예외 처리
└── requirements.txt        # 연구용 Python 패키지 의존성 목록
```

### 📌 임시 파일 관리 규칙 (`temp/` 폴더)
- 사용자 지침에 따라 **작업 중 생성되는 임시 저장 파일, 중간 체크포인트, 압축 해제 임시본 등은 반드시 `D:\paper\b\temp` 내에 생성**하여 관리합니다.
- `src.config.get_temp_path("filename")` 유틸리티 함수를 사용하여 경로를 일관되게 생성할 수 있습니다.
