# [대학원 머신러닝 프로젝트] The Apprentice Project 1
## AI-Hub 국내 여행로그 데이터 기반 여행객 성향 $\rightarrow$ 소비 지출액 예측 머신러닝 파이프라인

본 저장소는 **AI-Hub의 '국내 여행로그 데이터(동부권, 2023)' (데이터셋 #71778)**를 활용하여, 대학원 머신러닝 과제 평가 기준표(1~5단계 미션)와 2024~2025년 최신 Tabular 스케일링 기법 비교 요구사항을 충족하도록 구축된 엔드투엔드(End-to-End) 머신러닝 프로젝트입니다.

---

## 📌 [핵심] 원천 데이터(89.6 GB) 중 특정 일부 데이터만 선별·활용한 사유

AI-Hub 원천 데이터(#71778)는 총 **89.6 GB**(사진 74GB, GPS 트랙 207MB, POI 마스터 1.7GB, 가공 라벨 14.5GB, 관계형 CSV 테이블)에 달하는 방대한 멀티모달 데이터셋입니다.  
본 프로젝트에서는 이 중 **여행객 사전 성향/프로필 및 소비 지출 결합 데이터(2,880건, 14개 특징 변수)**를 선별 추출하여 분석에 활용했습니다. 그 구체적인 학술적·공학적 사유는 다음과 같습니다:

```
[원천 89.6 GB 데이터 필터링 및 선별 구조]

  원천 데이터 (89.6 GB)
  ├── [제외] 현장 촬영 사진 (74.0 GB)       ──► 여행 사후 산출물 (성향 모델링과 무관, 계산 낭비)
  ├── [제외] 초단위 GPS 트랙 (207 MB)       ──► 고주파 궤적 잡음 (사전 소비 예측과 무관)
  ├── [제외] 사후 방문지 체류/만족도 (14.5 GB)──► ★ Target/Data Leakage 발생 변수 (사후 결과)
  └── [선별] 사전 성향 & 프로필 결합 테이블   ──► 2,880건의 여행자 정형(Tabular) 마스터 추출
            (8대 라이프스타일 성향 + 소득/연령 + 사전예약금 ──► 총 소비 지출액 예측)
```

### 1. 도메인 연구 목적과의 일치성 (사전 성향 기반 예측)
- **과제 핵심 질문**: *"여행자가 여행을 떠나기 전 설문 또는 프로필로 확인 가능한 라이프스타일 성향(자연 vs 도시, 알뜰 vs 플렉스 등 8대 스타일)만으로 총 여행 경비를 사전에 산정할 수 있는가?"*
- 원천 데이터의 80% 이상을 차지하는 고용량 사진 파일(74GB)과 초 단위 GPS 트래킹 로그(207MB)는 **여행 도중/종료 후(In-trip / Post-trip)**에 취득되는 결과물입니다. 따라서 '여행 전(Pre-trip) 여행객 성향 기반 소비 예측'이라는 연구 가설 및 비즈니스 목적에 부합하지 않아 과감히 제외했습니다.

### 2. 타깃 누락(Target / Data Leakage)의 원천 차단
- 원천 데이터의 방문지 테이블(`tn_visit_area_info_`)에는 실제 방문한 장소 수(`VISIT_AREA_NUM`), 체류 시간(`STAY_TIME_MIN`), 사후 만족도(`DGSTFN`), 재방문 의향 등이 기록되어 있습니다.
- 이러한 변수들은 **소비 지출이 이미 일어난 뒤에만 측정될 수 있는 사후 결과 변수**입니다. 이를 입력 변수($X$)로 포함하면 인과관계 역전으로 인한 치명적인 Target Leakage가 발생하여 실전 예측 가치가 0이 되므로, 엄격한 사전 변수로만 데이터를 한정했습니다.

### 3. 데이터 계층 정규화 및 분석 단위(Trip Level) 일치
- 원천 데이터는 GPS 포인트(수백만 행), 방문지(수만 행), 지출 영수증(수만 행) 등 서로 다른 세분성(Granularity)의 테이블로 분산되어 있습니다.
- 분석 목표인 **'여행자 1인의 1회 여행 총 지출액'**에 부합하도록 여행 마스터(`tn_travel_`) 및 여행자 프로필(`tn_traveller_master_`)을 기준으로 현장 지출액(`tn_activity_consume_`)과 사전 예약금(`ADV_CONSUME_KRW`)을 여행 ID(`TRAVEL_ID`) 단위로 완벽히 집계·정규화하여 2,880건의 고품질 분석 매트릭스를 구성했습니다.

### 4. 연산 효율성 및 신호 대 잡음비(Signal-to-Noise Ratio) 극대화
- 89.6 GB 전체를 파이프라인 메모리에 적재할 경우 불필요한 이미지 픽셀 및 고주파 GPS 노이즈로 인해 막대한 I/O 병목과 연산 지연이 발생합니다.
- 소비 지출과 실질적 상관관계를 갖는 핵심 정형(Tabular) 변수 14개만 정밀 추출함으로써, 파이프라인 학습 속도를 수 초 단위로 단축하고 노이즈를 배제한 순수 성향 효과를 검증했습니다.

## 2. 과제 1~5단계 미션 수행 결과 요약

| 단계 | 핵심 수행 내용 | 과제 기준표 미션 질문 및 해결 결과 |
| :--- | :--- | :--- |
| **1. 문제 정의** | • 데이터: AI-Hub #71778 사전 성향 2,880건<br>• **입력변수($X$, 14개)**: 8대 성향 점수, 연령, 소득, 여행일수 등<br>• **출력변수($Y$)**: 총 지출액 (`TOTAL_EXPENDITURE`, 원)<br>• **유형**: **연속형 수치 회귀 (Regression)** | **[미션: 예측 문제 명확히 설정]**<br>여행 사후 변수를 원천 차단하고 순수 사전 성향으로 총 소비 지출액을 예측하는 회귀 문제로 정의 완료 (타깃 평균: 약 34.4만 원, 최대: 534만 원). |
| **2. 분할 비교** | • **전략 A**: Train:Test = 8:2 (2분할)<br>• **전략 B**: Train:Val:Test = 6:2:2 (3분할) | **[미션: 검증 데이터 유무에 따라 결과가 달라지는가?]**<br>$\rightarrow$ **예, 모델의 신뢰도와 과적합 통제 측면에서 극적인 차이가 발생합니다.**<br>2분할은 튜닝 시 테스트셋을 보게 되어 Data Leakage(간접 과적합)가 발생하지만, 3분할은 독립 검증셋으로 일반화 갭(Train $R^2$ 0.9239 vs Val $R^2$ 0.2073)을 사전에 모니터링하여 테스트셋을 온전히 보호합니다. |
| **3. 하이퍼파라미터 조정** | • 모델: **LightGBM Regressor**<br>• 기법: **Grid Search** (Validation RMSE 기준 최적 탐색)<br>• 파라미터: `n_estimators`, `max_depth`, `learning_rate`, `num_leaves` | **[미션: 하이퍼파라미터 조정이 필요한가?]**<br>$\rightarrow$ **예, 필수적입니다.**<br>기본 모델(RMSE 302,706.2원) 대비 최적화 모델(`depth=3, lr=0.03, n_est=100, leaves=15`) 적용 시 **오차가 13,538.1원(4.47%) 유의미하게 감소**했습니다. |
| **4. 스케일링 비교 (전통 vs 2025 최신)** | • **전통적 3종**: Raw, Standard, Min-Max, Robust<br>• **2024~2025 최신 3종**: RankGauss, Yeo-Johnson, Adaptive Winsorization<br>• **Data Leakage 방지**: Train에만 fit, Val/Test는 transform | **[미션: 스케일링이 필요한가? 전통 vs 최신 기법 특성은?]**<br>$\rightarrow$ **예, 거리 기반 모델 보호 및 이상치 분산 안정화에 필수적입니다.**<br>초고액 지출자가 존재하는 우측 왜도 데이터에서 MinMax는 데이터를 [0, 0.1]로 뭉개지만, **StandardScaler** 및 **2025년형 Adaptive Winsorized Scaler**가 가장 우수한 검증 성능(RMSE 302,706.2원, $R^2$ 0.2833)을 기록했습니다. |
| **5. 최종 성능 평가** | • **유의사항 준수**: 테스트 데이터는 튜닝 종료 후 **최종 1회만 언락**<br>• 회귀 4대 지표 산출 | • **MAE (평균 절대 오차)**: **141,480.6 원**<br>• **MSE (평균 제곱 오차)**: $5.6 \times 10^{10}$<br>• **RMSE (제곱근 평균 제곱 오차)**: **236,844.3 원**<br>• **$R^2$ (결정계수)**: **0.5183** (사전 성향만으로 미지의 테스트셋 변동의 **51.8%를 설명**) |
