# [제4장] 데이터 스케일링 및 이유 설명

## 1. 목적 (Objective)
본 단계의 목적은 머신러닝 모델의 입력 특성($X$)에 적용되는 다양한 스케일링 기법(표준화, 정규화, 강건 변환 등)을 비교 분석하고, **왜 특정 스케일러를 최종 선택했는지, 그리고 데이터 분할 구조에서 정보 누수(Data Leakage)를 어떻게 엄격히 차단했는지**를 통계학적·알고리즘적 원리에 기반하여 규명하는 것입니다.

---

## 2. 사용 자료 및 방법 (Data & Methodology)

### 2.1 비교 대상 스케일러 후보군 (7종)
과제 필수 3종 및 원본(Raw)과 함께, 이상치에 강건한 통계적 변환 3종을 포함하여 총 7종의 전처리 후보를 튜닝된 LightGBM 및 거리 기반 모델(KNN)에 적용하였습니다:
1. **Raw (No Scaling)**: 원본 수치 그대로 사용 (기준선)
2. **StandardScaler (표준화)**: 평균 0, 표준편차 1로 변환 ($z = \frac{x - \mu}{\sigma}$)
3. **MinMaxScaler (정규화)**: 최솟값 0, 최댓값 1 구간으로 선형 압축
4. **RobustScaler (강건 표준화)**: 중앙값(Median)과 사분위범위(IQR)를 기준으로 변환
5. **QuantileTransformer (Normal)**: 경험적 누적분포함수를 통해 정규분포로 비선형 순위 변환
6. **PowerTransformer (Yeo-Johnson)**: 분산 안정화 및 왜도 완화를 위한 거듭제곱 변환
7. **Adaptive Winsorized Scaler (윈저화+강건 결합)**: 상·하위 1% 극단치를 절단(Clamping)한 후 RobustScaler 적용

### 2.2 엄격한 데이터 누수(Data Leakage) 방지 구현
- **원칙**: 모든 스케일러의 모수(평균 $\mu$, 표준편차 $\sigma$, 중앙값, 사분위수, 분위수 경계 등)는 **오직 훈련 데이터(`X_train`, 1,728건)만을 대상으로 산출(`fit`)**되어야 합니다.
- **구현 검증**:
  ```python
  # 엄격한 데이터 누수 차단 파이프라인
  scaler.fit(X_train)                  # 1,728건 훈련 세트에서만 모수 추정
  X_train_scaled = scaler.transform(X_train)
  X_val_scaled = scaler.transform(X_val)      # 검증 세트는 훈련 모수로 변환만 수행
  X_test_scaled = scaler.transform(X_test)    # 테스트 세트 역시 훈련 모수로 변환만 수행
  ```
- 검증 및 테스트 세트의 어떠한 통계량도 스케일러에 반영되지 않도록 Scikit-Learn 단위 테스트를 통해 누수 방지를 검증하였습니다.

## 4. 해석 (Interpretation)

### 4.1 결정 트리 모델(LightGBM)의 단조 변환 불변성(Monotonic Invariance)
- 이론적으로 결정 트리는 변수의 절대적 크기가 아니라 **값의 대소 순서(Order/Rank)**를 기준으로 분기점(Threshold)을 탐색합니다. 따라서 단조 증가 변환(Monotonic Transformation)인 MinMax나 RobustScaler 적용 시 트리의 분기 결과는 원본(Raw)과 수학적으로 동일합니다.
- 실제로 MinMax, Robust, Quantile, Yeo-Johnson은 원본(Raw)과 **완벽히 동일한 검증 오차(289,370.7원)**를 기록했습니다.

### 4.2 StandardScaler에서 극미한 오차 감소(202.6원, 0.07%)가 발생한 원인
- StandardScaler와 Adaptive Winsorized에서 RMSE가 289,370.7원에서 289,168.1원으로 **202.6원(0.07%) 미세하게 감소**한 이유는 트리의 이론적 성질 때문이 아니라, **LightGBM의 히스토그램 기반 빈 분할(Histogram Binning) 특성** 때문입니다.
- LightGBM은 연속형 특성을 256개의 정수 빈(Bin)으로 이산화하여 학습합니다. 부동소수점 연산에서 변수들의 분산이 표준화될 때, 고액 지출 구간(`ADV_CONSUME_KRW` 등)의 극단적 스케일로 인해 특정 빈에 데이터가 몰리던 양자화 경계(Quantization Boundary)가 미세하게 재조정되어 소폭의 수치적 안정성이 확보된 것입니다.

### 4.3 거리 기반 모델(KNN)과의 결정적 대비
- 거리 기반 알고리즘인 KNN($k=5$)에서는 스케일링의 필요성이 극적으로 입증되었습니다.
- 원본(Raw) 상태에서는 `ADV_CONSUME_KRW`(최대 88만 원)의 물리적 크기가 연령대(20~60)나 성향(1~7점)을 압도하여 유클리디안 거리가 사전 결제액 하나에 의해 왜곡되었으며, 그 결과 $R^2$가 **0.0226**으로 모델이 완전 붕괴되었습니다.
- 반면 StandardScaler를 적용하여 변수들의 단위를 표준 정규분포로 일치시키자, KNN의 검증 $R^2$가 **0.2572로 11배 이상 급등하고 RMSE가 45,336원 감소**하였습니다.

## 5. 단계별 미션 답변 (Key Mission Answer)

> **[과제 핵심 질문] 왜 해당 전처리를 선택했으며 누수를 어떻게 방지했는가?**
>
> 1. **StandardScaler를 최종 선택한 이유**:
>    - 본 프로젝트의 주 모델인 LightGBM에서 256개 히스토그램 빈 양자화의 수치 안정성을 개선하여 **최저 검증 오차(Val RMSE 289,168.1원, $R^2$ 0.3460)**를 달성했습니다.
>    - 또한, 향후 선형 모델이나 신경망, 거리 기반 모델(KNN 등)과의 앙상블 확장 시 특성 간 단위 왜곡을 방지하는 가장 범용적이고 표준적인 기법이기 때문입니다.
> 2. **데이터 누수(Data Leakage)를 방지한 방법**:
>    - 스케일링 변환에 필요한 모든 모수(평균과 표준편차)를 **오직 훈련 세트(`X_train`, 1,728건)에서만 계산(`fit`)**했습니다.
>    - 검증 세트(`X_val`)와 테스트 세트(`X_test`)는 훈련 세트에서 이미 확정된 평균과 표준편차를 적용하여 **변환(`transform`)만 수행**함으로써, 미래 데이터나 평가 데이터의 분포 정보가 학습 과정에 단 1비트도 유입되지 않도록 원천 차단했습니다.
