# 과제 종합 검증 결과 및 평가 기준표 대응 요약

## 1. 개요

본 문서는 머신러닝 과제 평가 기준표의 5가지 단계별 핵심 질문에 대해, 실제 AI-Hub 원천 데이터(#71778)와 코드베이스 감사 증거를 바탕으로 사람이 직접 작성한 것처럼 정리한 종합 요약본입니다.

과거 초안에서 지적받았던 과장된 표현(예: 성향만으로 지출을 다 설명한다거나, 특정 전처리가 2025년 최신 기법이라는 등)을 걷어내고, 원천 데이터의 수치와 실제 실험 결과에 맞추어 사실 그대로 수정했습니다.

## 3. 주요 수정 및 팩트 교정 내용

1. **표본 수 320건 차이의 실체**: 
   - 기존에는 "영수증 결측으로 320건이 빠졌다"고 설명했으나, 실제 원천 데이터 확인 결과 배포 패키지(TL 2,560건 + VL 320건)의 합계가 2,880건이었고 제공된 전수가 100% 온전히 추출된 것임을 밝혔습니다.
2. **지출액 산식의 실체**: 
   - 기존에는 "활동과 사전예약금만 더했다"고 잘못 적혀 있었으나, 실제 코드는 활동 + 숙박 + 이동 + 사전예약금 4개 테이블 영수증 금액을 모두 합산한 것임을 확인하고 수식을 바로잡았습니다 (편차 0.0원).
3. **성향 변수의 실제 기여도**: 
   - "순수 성향 8개만으로 51.8%를 설명한다"는 과장된 주장을 바로잡기 위해 변수 제거 실험을 진행했습니다. 성향 8개만 넣었을 때의 $R^2$는 0.0186(1.9%)에 불과하며, 여행일수나 동반자수 같은 계획 변수가 기본 규모를 잡고 성향은 이를 미세 조정(+0.7%p)해 주는 역할을 한다는 사실을 객관적으로 입증했습니다.
4. **오차 지표 표기 분리**: 
   - 1박2일과 2박3일에서 나타난 5천 원대의 작은 오차는 '집단 전체의 평균 편향'이며, 개별 여행자 한 명 한 명의 평균 오차(MAE)는 7만~16만 원대임을 표에서 명확히 분리하여 혼동을 없앴습니다.
5. **과장된 어조 제거**: 
   - '2025 SOTA 스케일러', '완벽한 차단', '압도적 성능' 등 인공지능 특유의 상투적이고 과장된 수식어를 모두 지우고, 대학원 과제에 걸맞은 담백하고 정직한 학술 문장으로 전면 재구성했습니다.
