# [과제 종합 검증 결과 및 과제 요구사항 대응표] 00_검증결과_및_과제대응표

## 1. 개요 및 보고서 성격

본 보고서는 대학원 머신러닝 과제 기준표의 5대 핵심 질문에 대해, 인위적인 방어나 과장된 수식어를 배제하고 **실제 AI-Hub 원천 데이터(#71778)와 코드베이스 감사 증거에 기반하여 전면 재작성한 최종 개정 보고서**입니다.

과거 1차 원고에서 지적된 10대 학술 쟁점(표본 수 차이, 지출액 산식, 18열 구조, 성향 기여도 과장, 테스트 세트 사전 노출 이력 등)을 객관적 실측 데이터로 규명하고, 통계학 및 기계학습의 표준적 방법론에 따라 투명하게 교정하였습니다.

## 2. 과제 평가 기준표 5단계 대응 요약

| 단계 | 과제 필수 수행 내용 | 본 보고서의 핵심 답변 (반드시 답할 질문) | 구현 증빙 및 데이터 |
| :---: | :--- | :--- | :--- |
| **1단계** | **데이터셋 획득 및 문제 정의**<br>- 공개데이터 활용<br>- $X$·$Y$ 정의<br>- 분류/회귀 결정 | **[질문] 어떤 데이터로 무엇을 예측하는가?**<br>$\rightarrow$ AI-Hub '국내 여행로그(동부권)' 2,880건의 출발 전 수집 정보(성향 8개, 인구통계 3개, 계획 3개 = 총 14개 사전 변수)로 여행 후 영수증 집계 '관측 총지출액'을 예측하는 **연속형 수치 예측(회귀, Regression)** 문제입니다. | `real_travel_dataset.csv`<br>(14개 $X$ + 1개 $Y$, 사후 3개 변수 배제) |
| **2단계** | **데이터 분할 및 비교**<br>- Train/Test vs Train/Val/Test<br>- 검증 유무 성능 차이 분석 | **[질문] 검증 데이터가 있을 때 무엇이 달라지는가?**<br>$\rightarrow$ 검증 데이터는 **학습 중 과적합(Overfitting)을 객관적으로 감지하고 모델 후보를 공정하게 선택할 수 있는 판단 기준을 제공**합니다. 검증 세트 없이 학습 데이터만 볼 경우 훈련 오차($R^2 \approx 0.92$)에 현혹되어 실전 성능($R^2 \approx 0.28$)과의 극심한 괴리를 인지하지 못합니다. | `split_comparison.csv`<br>(내부 비교세트 $H$ 기준 전략 A vs B) |
| **3단계** | **하이퍼파라미터 조정**<br>- Grid Search 수행<br>- Validation 성능 기준 선택 | **[질문] 하이퍼파라미터 조정이 필요한가?**<br>$\rightarrow$ **절대적으로 필요합니다.** 본 데이터셋에서 LightGBM 기본 설정은 훈련 $R^2$ 0.81 vs 검증 $R^2$ 0.28로 심각한 과적합을 보였으나, 108개 그리드 탐색을 통해 깊이를 3으로 제한하고 학습률을 낮춘 최적 파라미터 적용 시 **검증 RMSE가 13,538원(4.47%) 감소하고 과적합 격차가 60.4% 축소**되었습니다. | `grid_search_results.csv`<br>(깊이 3과 리프 8의 종속성 정합 확인) |
| **4단계** | **데이터 스케일링 및 이유 설명**<br>- Standard·MinMax·Robust 비교<br>- 누수(Leakage) 방지 | **[질문] 왜 해당 전처리를 선택했으며 누수를 어떻게 방지했는가?**<br>$\rightarrow$ 비선형 트리 모델(LightGBM)은 단조 변환에 이론적으로 불변이나, 이상치 구간의 히스토그램 빈 양자화 안정성을 위해 **StandardScaler**를 최종 채택했습니다. 거리 기반 모델(KNN)에서는 스케일링 미적용 시 $R^2$ 0.02로 붕괴되던 모델이 0.26으로 복원되었습니다. 모든 스케일러는 **오직 Train(1,728건)에만 `fit`하고 Val/Test는 `transform`만 수행**하여 누수를 차단했습니다. | `scaler_comparison.csv`<br>(Train 전용 fit 단위 테스트 통과) |
| **5단계** | **최종 성능 평가**<br>- MAE·MSE·RMSE·R² 지표<br>- Test 최종 평가 | **[질문] 미사용 데이터에서 어느 정도 일반화되는가?**<br>$\rightarrow$ 최종 모델은 독립 테스트 세트(576건)에서 **MAE 141,480.6원 (중앙 오차 83,896원), RMSE 236,844.3원, $R^2$ 0.5183**을 기록했습니다. 1박2일과 2박3일에서는 집단 평균 편향이 5천 원대(오차율 1~3%)로 우수했으나, 3박 이상의 고액 장기 여행에서는 보수적 과소추정이 발생하는 명확한 일반화 한계가 관찰되었습니다. | `final_metrics.json`<br>`group_metrics.csv` (편향과 MAE 분리) |

## 3. 1차 검증 지적 사항 교정 총괄표

| 쟁점 번호 | 지적 사항 | 기존 원고의 오류·과장 | 개정본의 사실 기반 수정 내용 |
| :---: | :--- | :--- | :--- |
| **01** | 순수 성향 주장 | "순수 8대 성향만으로 51.8% 설명" | **변수 제거 실험(Ablation) 수행**: 성향 단독 $R^2$는 0.0186에 불과하며, 계획 변수(일수·동반자·사전결제)가 기저를 형성하고 성향이 이를 미세 조정함을 정직하게 보고. |
| **02** | 320건 제외 사유 | "영수증 결측 및 매칭 실패로 320건 탈락" | **표본 흐름표 제시**: 원천 배포본(TL 2,560건 + VL 320건)의 합계가 정확히 2,880건이며, 제공된 전체 표본이 100% 온전히 반영되었음을 증명. |
| **03** | 지출액 산식 | "활동과 사전만 더하고 숙박·이동은 제외" | **산출식 정정**: 활동(ACT) + 숙박(LOD) + 이동(MVM) + 사전(ADV) 4개 테이블 전수 합산 사실을 명시하고 Diff 0.0원 확인. |
| **04** | 테스트 사용 이력 | "5단계에서 최초 1회만 언락" | **경로 B 채택 및 투명 보고**: 2단계 평가 이력을 인정하고 수치를 `legacy/exploratory`로 분류. 2단계는 내부 비교세트 $H$로 재구성. |
| **05** | 15열 vs 18열 | 열 개수 불일치 및 사후 변수 누수 우려 | **데이터 사전 공개**: 14개 사전 입력 + 1개 타깃 + 3개 사후 보관열(모델 입력에서 100% 차단)의 구조를 명확히 명세. |
| **06** | 파라미터 중복 | max_depth=3에서 num_leaves 15, 31, 63 중복 | **이론적 한계 인정**: 깊이 3에서 최대 리프 8개 자동 상한을 명시하고, 유효 자유도 분석 표 수록. |
| **07** | 순서 역전 | 106위(308,467원)와 107위(307,976원) 역전 | **전수 재정렬**: RMSE 기준 오름차순으로 1위부터 108위까지 완벽 재정렬. |
| **08** | 시대적 과장 | 2000년 발표된 Yeo-Johnson을 '2025 SOTA'로 표기 | **학술 용어 격하**: '2025 SOTA' 수식어를 삭제하고 '비모수적 분위수 변환 및 강건 이상치 완화 기법'으로 교정. |
| **09** | RMSE 왜곡 | 튜닝 후 RMSE 증가(23.5만 $\rightarrow$ 23.6만)를 '유지'로 포장 | **정직한 지표 보고**: MAE는 8,223원 감소(-5.5%)했으나 RMSE는 1,770원 증가(+0.7%)했음을 밝히고, L1 vs L2 손실함수 민감도로 해석. |
| **10** | 오차 지표 혼동 | 집단 평균 차이(5천원)를 예측 정확도로 오인 유도 | **지표 명확 분리**: 집단 평균 편향(Mean Bias: 5천원)과 개별 샘플 MAE(7만~16만원)를 별도 열로 분리 표기. |
