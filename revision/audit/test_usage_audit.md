# [테스트 세트 사용 이력 감사 및 평가 경로 결정서] Test Usage Audit & Decision

## 1. 테스트 데이터 과거 사용 이력 감사 (Audit Findings)

코드베이스(`src/models/ml_pipeline.py`) 및 기존 보고서(`02_데이터_분할_및_비교.md`, `05_최종_성능_평가.md`)의 실행 기록을 정밀 조사한 결과는 다음과 같습니다:

1. **2단계에서의 테스트 접근**:
   - `execute_split_comparison()` 함수(lines 116-164)에서 2분할(8:2) 모델 평가 시 `X_te_2` 및 `y_te_2`에 대해 RandomForest의 성능($R^2 = 0.5040$)을 측정하여 출력 및 보고서에 기록함.
   - 이 `X_te_2`(576건)는 3분할의 `X_test`(576건)와 `random_state=42`에서 정확히 동일한 표본임.
2. **5단계에서의 테스트 접근**:
   - 3단계 하이퍼파라미터 튜닝이 완료된 후, `execute_final_evaluation()`에서 해당 576건의 테스트 세트에 대해 튜닝된 LightGBM 모델의 최종 성능(MAE 141,480.6원, RMSE 236,844.3원, $R^2 = 0.5183$)을 평가함.
3. **과제 조건과의 정합성 판정**:
   - 과제 지침의 핵심 유의사항인 **"테스트 데이터는 모든 튜닝이 끝난 뒤 최종 1회만 사용한다"**는 원칙에 비추어 볼 때, 2단계에서 분할 비교를 목적으로 테스트 세트를 사전 평가한 것은 엄격한 의미에서 '미사용 격리(Pristine Holdout)' 원칙을 훼손한 이력입니다.
   - '최초 열람'이라는 문구를 '동결 후 공식 최종 검증'으로 완곡하게 바꾼다 하더라도, 과거 실행 이력 자체를 소급하여 삭제할 수는 없습니다.

## 2. 평가 경로 결정: [경로 B] 채택

지시서 제5조에 규정된 두 가지 경로 중 **[경로 B]**를 정식 채택합니다:

### 2.1 경로 B 채택 이유
- 현재 로컬 환경에 확보된 유효 원천 데이터는 2,880건이 전부이며, 완전히 독립된 새로운 AI-Hub 공식 미배포 평가 데이터(새로운 권역 또는 비공개 테스트 세트)가 존재하지 않습니다.
- 기존 데이터를 다른 랜덤 시드로 단순히 다시 분할하는 것은 진정한 의미의 '새 독립 데이터'가 아니며, 학술적 속임수에 불과합니다.
- 따라서 과학적 진실성과 연구 윤리에 입각하여 **경로 B(기존 테스트 평가 이력을 투명하게 밝히고, 기존 수치는 `legacy/exploratory`로 분류하여 한계와 함께 보고)**를 채택합니다.

### 2.2 개정 작업 시 취한 조치
1. **과거 결과의 투명한 라벨링**:
   - 기존에 산출된 테스트 결과($R^2 = 0.5183$, RMSE = 236,844.3원 등)는 **`[Legacy 탐색적 평가 결과]`**로 명시하고, 모델 설계 과정에서 사전 노출되었을 가능성이 있는 '사후적 검증치'임을 명확히 한계로 서술합니다.
2. **2단계 내부 비교 실험 재설계 (지시서 제5.4조 준수)**:
   - 개정된 파이프라인에서는 테스트 세트(576건)에 일체 손대지 않고, **개발 데이터 내부(Train 1,728건 + Val 576건)**에서 검증 세트를 **공통 개발용 비교 평가 세트($H$)**로 활용하여 전략 A(고정 모델)와 전략 B(검증 기반 튜닝 모델)를 공정하게 비교합니다.
3. **최종 테스트 재실행 차단**:
   - 사용자의 명시적 승인이 없는 한, 테스트 세트에 대한 자동 재평가를 코드 수준에서 차단(`safe_ml_pipeline.py`)합니다.
